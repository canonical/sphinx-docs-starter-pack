Canonical's Sphinx Starter Pack 1.6
===================================

16 March 2026

These release notes cover new features and changes in Canonical's Sphinx Starter Pack
1.6. The `full commit log
<https://github.com/canonical/sphinx-docs-starter-pack/releases/tag/1.6>`__ is available
on GitHub.

Bring these changes into your docs:

- :ref:`Update starter pack 1.3.0 and higher <update-new-starter-pack>`
- :ref:`Update starter pack 1.2.0 and lower <update-legacy-starter-pack>`


What's new in 1.6
-----------------


New extension for redirects
~~~~~~~~~~~~~~~~~~~~~~~~~~~

If your project has a lot of redirects, you'll know how quickly they can begin to
clutter your build configuration file. To get around this, we've changed the default
extension for redirects to ``sphinx-rerediraffe``, a fork of the ``sphinxext-rediraffe``
extension.

You can now define your redirects in a ``redirects.txt`` file and configure your
project to use them with:

.. code-block:: diff
    :caption: conf.py
    :class: no-copybutton

    - redirects = {
    -     "source-path": "destination-path"
    - }
    + rediraffe_redirects = "redirects.txt"
    + rediraffe_dir_only = True

The ``sphinx-rerediraffe`` fork adds support for external redirects and aligns
destination URLs with our current practices.


Remote cookie banner files
~~~~~~~~~~~~~~~~~~~~~~~~~~

Following the recent changes to our RTD cookie banner, we evaluated how its files are
distributed and maintained. In version 1.6, these files are now hosted centrally and
no longer need to be duplicated in every project collecting analytics.

To enable Google Analytics with the new method, follow the steps in :ref:`Enable Google
Analytics <how-to-enable-google-analytics>`.

If you've already enabled Google Analytics in your project, you should make it a
priority to use the centrally-hosted files, as they contain important legal changes.
Once you update your Starter Pack, be sure to remove your local copies of
``cookie-banner.css`` and ``bundle.js``.


Virtual environment path
~~~~~~~~~~~~~~~~~~~~~~~~

We've moved the Python virtual environment from ``docs/.sphinx/venv`` to ``docs/.venv``.
Once you've replaced all occurrences of the old path, remove the old virtual
environment.


Ulwazi testing guide
~~~~~~~~~~~~~~~~~~~~

Our new Sphinx theme based on the Vanilla framework, Ulwazi, has been is now available
for testing. To try it out, follow the :ref:`how-to-test-ulwazi-theme` guide we
published.


Starter Pack explanation
~~~~~~~~~~~~~~~~~~~~~~~~

We published :ref:`explanation-structure` to explain the functionality of and
relationships between the core elements of the Starter Pack.


Deprecated features
-------------------

The following features are deprecated and will be removed in an upcoming version of
the Starter Pack.


``sphinx-reredirects``
~~~~~~~~~~~~~~~~~~~~~~

The ``sphinx-reredirects`` extension was deprecated in 1.6. Redirects, both internal and
external, should now be declared the ``sphinx-rerediraffe`` extension.


Fixed for 1.6
-------------

- `#535 <https://github.com/canonical/sphinx-docs-starter-pack/pull/535>`__ Markdown
  checks are incompatible with default runner version
- `#550 <https://github.com/canonical/sphinx-docs-starter-pack/issues/550>`__ Makefile
  doesn't allow for pymarkdownlnt to exit with a status code of 1
